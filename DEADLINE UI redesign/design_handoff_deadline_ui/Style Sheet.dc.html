05 · Building it as a Godot theme
One StyleBoxFlat per state
Each component above is four StyleBoxFlat resources — normal / hover / pressed / disabled — differing only in bg_color, border_color and border_width_*. Set anti_aliasing = false so 1px borders stay 1px, and keep content_margin_* equal across the four so text never shifts on hover.
Texture, when you want it
Where a panel should read as metal or card, swap the flat box for a StyleBoxTexture 9-slice with 6px margins and the same border colour painted into the edge. No blur, no drop shadows, no per-pixel effects: depth comes from the three panel greys and the border ladder.
Fonts
Three FontFile resources: Oswald SemiBold, Barlow Regular + SemiBold, IBM Plex Mono Medium. All OFL, so they ship with the game. Turn on Text > Use Oversampling, and set tracking on the Theme's label variations rather than per-node.
Focus and keyboard
Selection and keyboard focus share one look: 2px #E0C24A. Give every grid a focus stylebox identical to selected, so arrow-key browsing and mouse selection are the same state and never stack two highlights on one element.
